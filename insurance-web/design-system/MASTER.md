# 保顾智库工作台视觉规范

用户指定：黑白、中文圆体、红色预警。维持原生 JavaScript / Node.js / SQLite。

配色：ink #171717；surface #ffffff；canvas #f5f5f5；muted #686868；border #e6e6e6；warning #b42332。警示背景由 warning 低透明度派生。

字体：本地资源圆体，正文 14–16px，辅助信息 12px，标题 26–30px，关键金额 32px。表格使用等宽数字。移动端关键数字适当缩小，不裁切。

布局：深色左侧导航，浅色内容画布；主区全部左对齐。经营总览呈现月度统计、走势与预警、3 位成员；保单、AI、客户使用独立视图。图表以实际保费为实线、月目标为虚线，提供可展开数值表。

```text
导航     月份 / 当前账号 / 录入
         标题与业务摘要
         首年保费 | 达成率 | 目标差额 | 开单
         销售走势与月目标       重点注意
         苏晴        许佳        林晓
```

审视与取舍：技能搜索匹配到 Data-Dense Dashboard，适合经营分析。搜索中的企业宣传入口、蓝橙配色和 Fira 字体不符合本项目，采用用户指定的黑白圆体。避免营销标语、无意义的英文眉题、重复卡片和整页堆叠表格；导航只提供实际可用视图。业务状态同时提供文字与颜色。

交互：按成员联动走势图和保单范围；预警可直接定位成员。表单与 AI 请求提供加载与错误反馈；保留键盘焦点；图表数值可通过表格读取；减少动画偏好时关闭过渡。375/768/1440px 验证。
