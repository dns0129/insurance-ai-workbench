# 保顾智库工作台视觉规范

维持中文圆体和红色预警，工作台采用深海蓝导航、浅灰蓝画布，以及靛蓝主操作色。技术栈为原生 JavaScript / Node.js / SQLite。

配色：主文字 #1b2740，导航 #172640，主操作色 #35488d，画布 #f2f5fa，资料与下一步 #17685e，预警 #b42332。暖色底专用于参考话术。业务状态同时提供文字与颜色。

字体：本地资源圆体，正文 14–16px，辅助信息 12px，标题 26–30px，关键金额 32px。表格使用等宽数字。移动端关键数字适当缩小，不裁切。

布局：深色左侧导航，浅色内容画布；主区全部左对齐。经营总览呈现月度统计、走势与预警、3 位成员；保单、AI、客户使用独立视图。图表以实际保费为实线、月目标为虚线，提供可展开数值表。

```text
导航     月份 / 当前账号 / 录入
         标题与业务摘要
         首年保费 | 达成率 | 目标差额 | 开单
         销售走势与月目标       重点注意
         苏晴        许佳        林晓
```

审视与取舍：保留业务工作台的结构和中文字体，颜色用来区分功能及内容角色。AI 回答先给结论，强调关键短语；正文渐进显示，引用、表格和代码等完整块按块显示。允许直接显示全文，减少动态效果时直接展示完整回答。

交互：按成员联动走势图和保单范围；预警可直接定位成员。表单与 AI 请求提供加载与错误反馈；保留键盘焦点；图表数值可通过表格读取；减少动画偏好时关闭过渡。375/768/1440px 验证。
