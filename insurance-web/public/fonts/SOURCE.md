# 圆体来源

`round-regular.woff` 与 `round-bold.woff` 来自 [Resource Han Rounded CN v0.990](https://github.com/CyanoHao/Resource-Han-Rounded/releases/tag/v0.990) 的 Regular、Bold 字体，按界面常用文字裁剪。

`round-supplement-regular.woff2` 与 `round-supplement-bold.woff2` 来自同一版本和字重。使用 fontTools 选取 GB2312 与 Big5 常用汉字区的字符，排除基础文件已有字形后转为 WOFF2。未覆盖的字符使用系统字体回退。
